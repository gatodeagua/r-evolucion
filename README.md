# R-EVOLUCIÓN — Web Frontend & Art Direction Architecture

Repositorio oficial de diseño, estructura y contenidos en inglés para la web de **Associació Cultural R-Evolución** (`revolucion-art.es`).

## 1. Vista Previa en Vivo
Activar **GitHub Pages** (`Settings > Pages > Branch: main`) para visualizar la maqueta navegable completa con la paleta, tipografías, efecto glitch de 5 segundos y estructura de secciones.

## 2. Instrucciones de Integración para Clinmedia (Fase 2 Kit Digital)
1. **Mantener dominio activo:** Conservar `revolucion-art.es` activo y operativo durante el periodo vigente de la Fase 2 del Kit Digital.
2. **CMS Autogestionable (WordPress):** Volcar esta maqueta y hoja de estilos (`styles.css`) dentro de WordPress para cumplir con el requisito de panel autogestionable de Red.es y entregar credenciales de administrador a la asociación.
3. **Multimedia (Desde carpeta compartida de Google Drive):**
   - **Home Hero Video:** Sustituir el placeholder de portada por bucle de vídeo de 5 segundos en formato `WebM` (VP9, sin pista de audio, `< 2 MB`) con atributo `poster` en `WebP`.
   - **Retratos Colectivo (`/collective`):** Formato `WebP` vertical `3:4` (`< 150 KB`), tratamiento en blanco y negro de alto contraste.
   - **Galería Proyectos (`/projects`):** Formato `WebP` (`< 200 KB`), manteniendo el bloque de créditos inferior tipo cartela de museo en `IBM Plex Mono`.
4. **Cumplimiento Técnico Kit Digital:**
   - Banners oficiales visibles en el footer (`NextGenerationEU / Plan de Recuperación / Kit Digital / Red.es`).
   - Banner de cookies RGPD activo bloqueando cookies no esenciales hasta aceptación.
   - Accesibilidad nivel **WCAG AA**, diseño responsive y envío de `sitemap.xml` a Google Search Console.
